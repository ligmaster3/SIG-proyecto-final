# Sistema Integrado de Gestión (SIG) - Biblioteca CRUBA

## Descripción General
Sistema de gestión integral para la biblioteca del CRUBA que permite la administración de recursos bibliográficos, préstamos de libros y uso de computadoras.

## Funcionalidades Principales

### Módulo de Autenticación
- Login unificado para estudiantes y administradores
- Control de acceso basado en roles
- Gestión de sesiones seguras

### Panel de Administración
- Dashboard unificado para administradores
- Gestión de inventario de libros
- Control de préstamos y devoluciones
- Monitoreo de uso de computadoras
- Reportes y estadísticas

### Portal de Estudiantes
- Búsqueda y solicitud de libros
- Reserva de computadoras
- Seguimiento de solicitudes
- Acciones rápidas personalizadas

## Tecnologías Implementadas
- Frontend: HTML5, CSS3, Bootstrap 5, JavaScript
- Backend: PHP 8.x
- Base de Datos: MySQL
- Iconografía: Bootstrap Icons
- Seguridad: PDO para consultas preparadas

## Mejoras Implementadas
- Interfaz visual moderna y responsiva
- Visualización de datos mejorada con gráficos
- Acciones rápidas optimizadas
- Sistema de notificaciones en tiempo real
- Panel de administración unificado

## Resultados Esperados
- Mejora en la experiencia de usuario
- Mayor eficiencia en el control de recursos
- Optimización de procesos administrativos
- Incremento en la satisfacción de usuarios
- reduce el tiempo de respuesta de la entrega
